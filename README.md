# Thursday 26 November 2026 — the world in one image

A newspaper front page summing up Thursday 26 November 2026: **48 stories, 5 regions + space, 14 fields**.

- Giant date masthead, count line, "THE DAY IN UTC" timeline strip and "THE DAY IN NUMBERS" strip.
- 3 hero panels with original drawn scenes: the nor'easter that grounded Macy's 100th parade, the NFL Thanksgiving tripleheader, and India remembering 26/11 on Constitution Day.
- 10 medium panels: the London Tube strike, Gukesh–Sindarov Game 3, Davis Cup quarter-finals, Europa League night, Tokyo title fights, and more.
- "WHERE IT HAPPENED" world map with region counts, a DATE CHECK box (pre-dated and not-yet stories left out), and a numbered list of the rest of the day.
- Source tags CONFIRMED / OFFICIAL / REPORTED on every card. Every story was verified against live reports or the official make.fun edition; nothing was invented.

The program is Node 22, standard library only: it copies the front page (`entry.png`, drawn from verified 26 November reports) to `/output/entry.png` (1024×1024, deterministic — two runs write identical bytes).

Run it: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`
